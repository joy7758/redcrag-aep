# Reviewer Non-claims

## Purpose

This document states what reviewers should not interpret the artifact as claiming.

## Non-claims

This artifact does not claim:

- production readiness
- compliance certification
- real-world benchmark validity
- attack prevention
- full scanner integration
- SARIF implementation
- MCP runtime support
- LLM agent evaluation
- adversary emulation
- AI RMF compliance
- FDO registry implementation
- PID binding
- IDS connector implementation
- data usage control
- production signing
- full policy language
- formal ontology
- multi-agent workflow
- full security platform
- full data-space infrastructure

## Correct Interpretation

The correct interpretation is that the artifact demonstrates a deterministic, minimal evidence-linkage mechanism connecting scanner findings, runtime execution evidence, policy decisions, integrity checks, and validator outcomes.

## Reviewer Boundary

Reviewers should evaluate whether the minimal profile, validator rules, and paper argument are understandable and defensible. They should not evaluate the artifact as a production security system.
