# Formatting and Numbering Plan

## Purpose

This plan prepares final formatting tasks that should happen only after the content and scope are stable.

## Figure Plan

- unify figure numbering
- assign final number to architecture figure
- decide whether to add one evidence-linkage figure
- remove duplicate figure references if any

## Table Plan

- unify table numbering across the full paper draft
- ensure model tables appear in the correct order
- ensure implementation tables appear in the correct order
- ensure evaluation tables appear in the correct order
- ensure discussion tables appear in the correct order

## Formatting Tasks

- align section heading style with venue
- remove leftover placeholder notes if converting to final submission copy
- reduce repeated caveats while preserving one strong boundary statement in limitations
- normalize capitalization of AEP / PASS / WARN / FAIL / FDO terms
- check line breaks and markdown table readability before venue conversion

## Not to Do Yet

- do not renumber tables before deciding target venue format
- do not remove source IDs before citation conversion plan is executed
- do not compress content at the cost of losing scope boundaries
