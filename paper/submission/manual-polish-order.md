# Manual Polish Order

## Purpose

This document defines the safest order for final manual polishing after the current clarification passes.

## Recommended Order

1. citation placeholder review
2. artifact citation decision
3. caveat compression review
4. section transition cleanup
5. figure/table numbering
6. appendix compression
7. abstract final trim
8. final proofread
9. reproducibility re-check

## Why This Order

- Citation and artifact handling affect many sections.
- Caveat compression should happen after scope is stable.
- Numbering should happen near the end.
- Final wording should not disturb frozen semantics.
- Reproducibility must be re-checked after all editorial work.

## Freeze Reminder

No manual polishing step should alter implementation behavior, profile semantics, validator semantics, PASS/WARN/FAIL meanings, or Future Work scope.
