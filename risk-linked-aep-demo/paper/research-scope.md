# Research Scope

## Current Research Line

This prototype belongs to the line of work on agent execution evidence, operational accountability, and FDO/data-space compatible evidence objects.

## Main Research Question

How can agent execution evidence be linked with pre-execution security findings to support verifiable accountability in FDO and data-space environments?

## In Scope

- minimal evidence profile
- execution event trace
- risk linkage
- validator rules
- deterministic accountability scenarios
- FDO-style evidence object shaping

## Out of Scope

- new vulnerability scanner
- agent marketplace
- real security product
- production compliance system
- full FDO registry
- multi-agent protocol
- MCP runtime integration
- LLM behavior evaluation

## Why This Boundary Matters

The contribution is not security scanning itself. The contribution is evidence linkage and validation. Keeping the prototype small makes the profile reviewable and reproducible.
