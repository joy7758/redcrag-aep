# Paper-facing Materials

The v0.1 review release index is available at `release/v0.1-review/README.md`.

- `contribution-statement.md`: frames the research gap, contribution, claim, and non-goals.
- `aep-profile-v0.1.md`: describes the AEP profile model in a standards-facing form.
- `validator-rules.md`: documents validator rules, aggregation logic, interpretation, and limits.
- `evaluation-section.md`: provides a paper-style evaluation section for the three scenarios.
- `research-scope.md`: defines the research boundary and next research steps.
- `architecture.mmd`: contains Mermaid source for the architecture diagram.
- `abstract-draft.md`: provides a concise academic abstract draft.

Suggested reading order:

1. `contribution-statement.md`
2. `aep-profile-v0.1.md`
3. `validator-rules.md`
4. `evaluation-section.md`
5. `research-scope.md`
