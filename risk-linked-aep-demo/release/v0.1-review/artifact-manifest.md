# Artifact Manifest

## Purpose

This manifest identifies the main artifacts included in the v0.1 review release.

## Implementation Artifacts

| Path | Role | Review relevance |
| --- | --- | --- |
| `profile/` | Stores AEP schemas and static examples. | Defines the profile artifacts reviewers can inspect. |
| `scanner-output/` | Stores deterministic scanner-style inputs and a normalizer. | Shows the pre-execution risk inputs used by the demo. |
| `agent/` | Stores deterministic agent behavior, tools, and policy. | Provides controlled runtime behavior for PASS/WARN/FAIL. |
| `collector/` | Stores evidence collection, hash-chain, and demo signing code. | Produces AEP event logs and bundles. |
| `validator/` | Stores validator CLI and rule logic. | Produces PASS/WARN/FAIL conclusions. |
| `demo/` | Stores input data and the all-scenario runner. | Reproduces the deterministic demo. |
| `scripts/` | Stores acceptance checks. | Verifies generated artifacts and fail-scenario evidence. |
| `runs/` | Stores generated run artifacts. | Contains event logs, bundles, and validation reports. |
| `Makefile` | Provides command wrappers. | Supports reviewer-friendly reproduction commands. |

## Profile and Schema Artifacts

| Path | Role | Review relevance |
| --- | --- | --- |
| `profile/aep-profile.schema.json` | JSON Schema for AEP bundles. | Documents bundle structure. |
| `profile/aep-event.schema.json` | JSON Schema for AEP events. | Documents event-level evidence structure. |
| `profile/normalized-risk-report.schema.json` | JSON Schema for normalized risk reports. | Documents scanner-finding input shape. |
| `paper/aep-profile-v0.1.md` | Standards-facing profile note. | Explains purpose, scope, bundle model, event model, risk linkage, and boundaries. |

## Demo and Evidence Artifacts

| Path | Role | Review relevance |
| --- | --- | --- |
| `runs/pass/aep-events.jsonl` | PASS event log. | Shows allowed execution evidence. |
| `runs/pass/aep-bundle.json` | PASS evidence bundle. | Shows manifest-level evidence for PASS. |
| `runs/pass/validation-report.json` | PASS validation report. | Shows validator conclusion. |
| `runs/warn/aep-events.jsonl` | WARN event log. | Shows high-risk finding not triggered. |
| `runs/warn/aep-bundle.json` | WARN evidence bundle. | Shows manifest-level evidence for WARN. |
| `runs/warn/validation-report.json` | WARN validation report. | Shows validator conclusion. |
| `runs/fail/aep-events.jsonl` | FAIL event log. | Shows denied `write_file` attempt blocked by collector. |
| `runs/fail/aep-bundle.json` | FAIL evidence bundle. | Shows manifest-level evidence for FAIL. |
| `runs/fail/validation-report.json` | FAIL validation report. | Shows validator conclusion. |

Generated `runs/` artifacts are reproducible and may be regenerated by `python3 demo/run_all.py`.
