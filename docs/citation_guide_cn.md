# RedCrag AEP v0.2-alpha 引用指南

## 推荐引用名称

RedCrag AEP（Agent Execution Profile，智能体执行证据配置文件）v0.2-alpha

## 推荐一句话引用

RedCrag AEP v0.2-alpha 是一个面向智能体关键动作的执行证据 profile（配置文件）与 validator（校验器）研究型工程原型，用于生成可签名、可校验、可复核的证据包。

## 推荐较长引用

RedCrag AEP（Agent Execution Profile，智能体执行证据配置文件）v0.2-alpha 是一个公开研究型工程资产。它围绕智能体关键动作执行证据，提供最小 profile（配置文件）、demo（demonstration，演示）级签名、validator（校验器）、specimen（样例集）、合同审查 demo，以及 OpenTelemetry（开放遥测标准）风格 trace（追踪记录）到 AEP 的自举验证。
