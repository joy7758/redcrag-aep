# RedCrag AEP v0.2-alpha 短版发布稿

RedCrag AEP（Agent Execution Profile，智能体执行证据配置文件）v0.2-alpha 已公开。

它不是智能体平台，也不是普通日志系统，而是面向智能体关键动作的执行证据 profile（配置文件）和 validator（校验器）研究型工程原型。当前版本包含合同审查 demo（demonstration，演示）、有效与无效样例、demo 级签名，以及 OpenTelemetry（开放遥测标准）风格 trace（追踪记录）到 AEP 的自举验证。

仓库地址：
https://github.com/joy7758/redcrag-aep

Release（发布页）：
https://github.com/joy7758/redcrag-aep/releases/tag/v0.2-alpha

边界：不证明模型一定正确，不替代法律意见，不保证合规，不保证安全。demo（demonstration，演示）级签名不是生产级法律签名，OpenTelemetry 当前只是风格映射。
