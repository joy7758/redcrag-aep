# RedCrag Trial Package One-Pager

## Problem

Agent systems can produce useful work, but customers often cannot answer basic audit questions: what action was taken, what evidence was used, whether a risky step had human approval, and whether an external action has a receipt.

## Delivery

The trial package delivers a minimal AEP evidence bundle, demo-grade signing, a validator, one valid specimen, four failing specimens, a contract review demo, and report templates for gaps and acceptance.

## Non-Commitments

This trial does not promise model correctness, production compliance, legal-risk transfer, customer-data ingestion, SaaS hosting, or production-grade legal signatures.

## Best Fit

The first fit is a contract review, customer support, or operational agent where a few high-risk actions need receipts, human review, and replayable evidence.

## Two-Week Pilot

Week 1: select one workflow, define critical actions, map inputs and outputs to references, and generate local AEP bundles.

Week 2: validate bundles, review failures, write a gap report, and decide whether to build an OpenTelemetry, Langfuse, CozeLoop, or MCP integration.
